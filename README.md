# Hidden King — 0.1 Beta

Windows beta releases and the signed application update feed. The application source is maintained separately.

## Download for Windows x64

[Download Hidden King 0.1 Beta](https://github.com/Xysud/hidden-king-releases/releases/download/v0.6.0-beta.2/Hidden-King-0.1-Beta-build-0.6.0-beta.2-x64-setup.exe) · [Release notes and checksums](https://github.com/Xysud/hidden-king-releases/releases/tag/v0.6.0-beta.2)

Close Deadlock and your current Hidden King before running Setup. Keep the default installation folder, then use the Hidden King Beta shortcut.

After installation, Hidden King Beta checks the beta channel for updates and offers an Update button. Profiles, mods and preferences remain on your computer. Close Deadlock and allow launch recovery to finish before updating.

## Public beta scope

AutoExec, Tracker, Map and Workshop are available only in Developer while development continues. They are hidden in the public beta.

The app displays **0.1 Beta**. Its technical updater build is `0.6.0-beta.2` so previously installed beta builds can receive the update.

The release named `beta` contains the update manifest only. Developer installers are kept separate and are not distributed through this channel.

## Feedback and known limitations

Report bugs through Issues with your app version, reproduction steps and screenshots. Never post Steam credentials or private logs. Some community models only support a static preview. Mod compatibility depends on the Deadlock build and the mod author.

This beta is distributed by invitation through a shared link. Downloads are public and the link can be forwarded.
