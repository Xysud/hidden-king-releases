## Features

- **Browse Mods** — discover community creations with search, filters, favorites and sorting.
- **Library** — enable, disable and reorder your installed mod packages.
- **Hero Customization** — explore skins, sounds and portrait cards for your heroes.
- **Optimization** — choose from community graphics presets in Performance.
- **Profiles** — keep different mod setups organized.
- **In-app updates** — check for signed launcher updates from Settings.

## Installation

Download the **Windows x64 installer** using the link above.

1. Close Deadlock and Hidden King.
2. Run Setup and keep the recommended installation folder.
3. Open **Hidden King Beta** and select your Deadlock installation if prompted.

## Updates

Go to **Settings → Updates → Check updates → Update and restart**. Hidden King downloads and verifies the signed update, then installs it once Deadlock is closed and recovery is complete. Your profiles, mods and preferences are preserved.
