# Hidden King — closed beta
Windows beta releases and the signed application update feed. The application source is maintained separately.
## Downloads
Download the installer from a versioned release on the [Releases page](https://github.com/Xysud/hidden-king-releases/releases). The first beta is being prepared; draft releases are not available to testers.
After installation, Hidden King Beta checks this channel for updates and offers an Update button. Profiles, mods and preferences remain on your computer. Close Deadlock and allow launch recovery to finish before updating.
The release named `beta` contains the update manifest. Download the setup executable from a versioned release instead. Developer installers are kept separate and are not distributed through this channel.
## Feedback and known limitations
Report bugs through Issues with your app version, reproduction steps and screenshots. Never post Steam credentials or private logs. Tracker history can be incomplete or delayed, and some community models only support a static preview. Mod compatibility depends on the Deadlock build and the mod author.
This beta is distributed by invitation through a shared link. Downloads are public and the link can be forwarded.
