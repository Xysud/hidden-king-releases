# Hidden King — closed beta

Windows beta releases and the signed application update feed. The application source is maintained separately.

## Download for Windows x64

[Download Hidden King Beta 0.6.0-beta.1](https://github.com/Xysud/hidden-king-releases/releases/download/v0.6.0-beta.1/Hidden-King-beta-0.6.0-beta.1-x64-setup.exe) · [Release notes and checksums](https://github.com/Xysud/hidden-king-releases/releases/tag/v0.6.0-beta.1)

Close Deadlock and your current Hidden King before running Setup. Keep the default installation folder, then use the Hidden King Beta shortcut.

After installation, Hidden King Beta checks the beta channel for updates and offers an Update button. Profiles, mods and preferences remain on your computer. Close Deadlock and allow launch recovery to finish before updating.

The release named `beta` contains the update manifest only. Developer installers are kept separate and are not distributed through this channel.

## Feedback and known limitations

Report bugs through Issues with your app version, reproduction steps and screenshots. Never post Steam credentials or private logs. Tracker history can be incomplete or delayed, and some community models only support a static preview. Mod compatibility depends on the Deadlock build and the mod author.

This beta is distributed by invitation through a shared link. Downloads are public and the link can be forwarded.
